# CN – Der Pflegedienst

High-end Website-Entwurf für **CN – Der Pflegedienst Christoph Strobel und Nikola Banicevic GbR** in Frankfurt am Main.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
